## Méthode statistique

Utilise la méthode **Khamis–Roche**, publiée en 1994 et corrigée en 1995.

Sources principales :

* https://pubmed.ncbi.nlm.nih.gov/7936860/
* https://publications.aap.org/pediatrics/article/94/4/504/59488/Predicting-Adult-Stature-Without-Using-Skeletal
* https://publications.aap.org/pediatrics/article/95/3/457/59792/ERRATUM

La formule générale est :

`taille adulte en pouces = B0 + B1 × taille actuelle en pouces + B2 × poids en livres + B3 × taille parentale moyenne en pouces`

Les coefficients changent selon le sexe et l’âge, tous les 0,5 an entre 4 et 17,5 ans.

La taille parentale moyenne est :

`(taille du père + taille de la mère) / 2`

Ne pas ajouter ou retirer 13 cm : le sexe est déjà pris en compte par les coefficients Khamis–Roche.

## Données autorisées dans le calcul

Le moteur utilise uniquement :

* sexe utilisé par le modèle : `male` ou `female` ;
* date de naissance ;
* date de mesure ;
* taille actuelle en centimètres ;
* poids actuel en kilogrammes ;
* taille du père biologique ;
* taille de la mère biologique.

L’origine, la pointure, l’acné, la pilosité, le sommeil, le sport et la taille rêvée ne doivent pas influencer la prédiction.

Aucun LLM ou appel à une intelligence artificielle ne doit intervenir dans le calcul.

## Exactitude des coefficients

Implémente :

* 28 lignes masculines ;
* 28 lignes féminines ;
* une ligne tous les 0,5 an ;
* de 4,0 à 17,5 ans ;
* quatre coefficients par ligne : `B0`, `B1`, `B2`, `B3`.

N’invente aucun coefficient.

La table doit tenir compte de l’erratum de 1995.

Pour chaque source utilisée pour reproduire la table, documente :

* son nom ;
* son URL directe ;
* sa date de consultation ;
* si elle utilise bien l’erratum ;
* les éventuelles différences trouvées.

Compare automatiquement :

* 56 lignes ;
* 224 coefficients.

Si la publication primaire complète n’est pas accessible, écris honnêtement :

**Table reproduite depuis des sources secondaires concordantes, mais non vérifiée directement contre le document primaire.**

Ne prétends jamais avoir effectué une vérification qui n’a pas réellement été réalisée.

## Calcul de l’âge

Crée :

`calculateDecimalAge(dateOfBirth, measurementDate)`

Le calcul doit considérer la date complète et fonctionner correctement :

* avant l’anniversaire ;
* le jour de l’anniversaire ;
* après l’anniversaire ;
* pendant les années bissextiles.

Refuse :

* date invalide ;
* date de mesure antérieure à la naissance ;
* âge inférieur à 4 ans ;
* âge supérieur à 17,5 ans.

N’extrapole jamais en dehors de cette plage.

## Âges intermédiaires

Pour un âge situé exactement sur une ligne de la table, utilise cette ligne.

Pour un âge situé entre deux lignes, effectue une interpolation linéaire des quatre coefficients.

Documente que cette interpolation est une décision d’implémentation de Grandimi et non une exigence explicitement imposée par l’étude originale.

Retourne les deux âges utilisés et le facteur d’interpolation.

## Conversions

Crée des fonctions pures :

* `cmToInches`
* `inchesToCm`
* `kgToPounds`

Effectue :

1. conversion des tailles en pouces ;
2. conversion du poids en livres ;
3. calcul Khamis–Roche en unités impériales ;
4. conversion du résultat en centimètres.

N’effectue aucun arrondi intermédiaire.

Arrondis seulement la valeur finale affichable à 0,1 cm.

## Validation

Refuse explicitement :

* valeur manquante ;
* valeur non numérique ;
* `NaN` ;
* valeur infinie ;
* valeur négative ;
* donnée située en dehors des limites.

Limites initiales :

* taille actuelle : 80 à 220 cm ;
* poids actuel : 10 à 200 kg ;
* taille de chaque parent : 120 à 230 cm.

Ne remplace jamais une taille parentale inconnue par une moyenne de population.

## Avertissements obligatoires

Chaque résultat doit préciser que :

* c’est une estimation statistique ;
* ce n’est pas un diagnostic médical ;
* la méthode n’utilise pas l’âge osseux ;
* une puberté précoce ou tardive peut réduire sa fiabilité ;
* l’étude originale portait sur des enfants blancs américains en bonne santé ;
* son utilisation sur d’autres populations est une extrapolation ;
* des mesures imprécises modifient le résultat ;
* aucun mode de vie ne garantit une taille particulière.

## Procédure en cas de problème

Ne modifie pas le code au hasard.

Pour chaque écart supérieur à 0,5 cm :

1. formule au moins trois hypothèses ;
2. classe-les par probabilité ;
3. définis comment les tester ;
4. teste-les une par une ;
5. identifie la cause confirmée ;
6. corrige uniquement la cause ;
7. relance tous les tests ;
8. documente le résultat.

Vérifie notamment :

* erreur d’unité ;
* mauvais coefficient ;
* erratum absent ;
* mauvais calcul de l’âge ;
* arrondi prématuré ;
* mauvaise moyenne parentale ;
* différence d’interpolation.
