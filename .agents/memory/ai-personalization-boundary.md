---
name: AI personalization boundary
description: Durable privacy and integrity rules for Grandimi's optional AI-written copy.
---

AI personalization is only an optional text overlay applied after deterministic report and program generation. The browser sends coarse profile signals and deterministic action IDs; the server resolves titles from its shared trusted registry before prompting or grounding output.

**Why:** Accepting action titles or numeric results from the browser would let personalized copy drift from the validated program or imply that AI controls deterministic growth calculations.

**How to apply:** Keep prediction numbers, exact measurements, dates, parent data, and raw development answers outside AI payloads. Never allow generated copy to modify report values or action objects. Cache only validated copy by deterministic program identity and retain a complete deterministic fallback.
