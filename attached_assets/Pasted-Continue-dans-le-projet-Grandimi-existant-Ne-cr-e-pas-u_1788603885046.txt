OBJECTIF PRODUIT

Quand l’utilisateur appuie sur « Créer mon programme de 7 jours » depuis `/result-preview`, il doit accéder à un vrai programme personnalisé construit à partir de ses réponses.

Le programme doit aider l’utilisateur à améliorer les habitudes qui soutiennent une croissance normale :

* sommeil ;
* activité physique et récupération ;
* alimentation et hydratation.

Chaque journée doit contenir exactement trois actions :

1. une action sommeil ;
2. une action activité/récupération ;
3. une action alimentation/hydratation.

À cette étape :

* aucun LLM ;
* aucun appel API ;
* aucun paiement ;
* aucun compte ;
* aucune base de données ;
* aucun bouton « Fait » ou « Remplacer » fonctionnel ;
* aucun coach conversationnel.

L’objectif est d’abord de construire une bibliothèque fiable et un générateur déterministe. Le LLM sera connecté à l’étape suivante pour reformuler et adapter ces actions sans pouvoir en inventer de nouvelles.

BIBLIOTHÈQUE D’ACTIONS

Créer suffisamment d’actions pour que les programmes soient réellement différents selon les réponses.

Chaque catégorie doit contenir au minimum :

* 10 actions principales ;
* 2 ou 3 alternatives compatibles pour chaque type d’action ;
* plusieurs niveaux de difficulté ;
* des actions adaptées aux utilisateurs déjà réguliers ;
* des actions simples pour les utilisateurs peu actifs.

Les actions doivent être concrètes et vérifiables.

Mauvais exemple :

« Dors mieux. »

Bon exemple :

« Pose ton téléphone hors du lit 30 minutes avant ton heure habituelle de coucher. »

Mauvais exemple :

« Mange sainement. »

Bon exemple :

« Ajoute aujourd’hui une source de protéines et un fruit ou un légume à l’un de tes repas. »

Ne pas prescrire :

* médicaments ;
* hormones ;
* compléments alimentaires ;
* vitamines ou minéraux à dosage médical ;
* régimes amaigrissants ;
* calories personnalisées ;
* jeûne ;
* exercices prétendant allonger les os ;
* entraînements dangereux ;
* traitement d’une maladie.

RÈGLES SOMMEIL

Utiliser l’âge pour sélectionner le repère approprié :

* 3–5 ans : 10 à 13 heures par 24 heures ;
* 6–12 ans : 9 à 12 heures ;
* 13–18 ans : 8 à 10 heures.

Adapter les actions selon :

* durée déclarée ;
* régularité des horaires ;
* écrans avant le coucher ;
* difficulté éventuelle déjà déclarée.

Si le sommeil est insuffisant, il devient généralement la priorité principale.

Si le sommeil est déjà adapté, proposer des actions de maintien et de régularité plutôt que de déclarer un problème inexistant.

Ne jamais recommander de rester au lit excessivement.

RÈGLES ACTIVITÉ ET RÉCUPÉRATION

Utiliser comme repère :

* environ 60 minutes d’activité physique modérée à soutenue par jour pour les 5–17 ans ;
* activités renforçant muscles et os au moins trois jours par semaine.

Adapter selon :

* nombre d’entraînements déclarés ;
* niveau d’activité ;
* éventuelle fatigue ;
* habitudes actuelles.

Si l’utilisateur ne fait presque aucune activité :

* commencer progressivement ;
* proposer marche dynamique, mouvements simples ou activité choisie ;
* éviter un programme trop intense.

Si l’utilisateur s’entraîne déjà fréquemment :

* ne pas ajouter automatiquement davantage d’entraînement ;
* privilégier récupération, mobilité légère, régularité et journée moins intense lorsque nécessaire.

La posture peut être présentée comme améliorant l’alignement ou la manière de se tenir, jamais comme un moyen d’allonger les os.

RÈGLES ALIMENTATION ET HYDRATATION

Adapter les actions selon :

* repas sautés ;
* hydratation insuffisante ;
* diversité alimentaire ;
* réponses disponibles dans l’onboarding.

Les actions doivent favoriser :

* régularité des repas ;
* diversité ;
* sources alimentaires de protéines ;
* fruits et légumes ;
* eau ;
* alimentation suffisante et équilibrée.

Ne pas inventer un besoin individuel précis en litres, calories, protéines, calcium ou vitamines si les données nécessaires ne sont pas disponibles.

Si aucune difficulté n’est déclarée, proposer des actions de maintien plutôt que créer artificiellement un problème.

PERSONNALISATION

Le programme doit utiliser les priorités déjà identifiées dans le rapport.

Exemples :

* sommeil court + écrans → actions progressives sur le coucher et les écrans ;
* aucune activité → démarrage progressif ;
* entraînement fréquent → récupération et régularité ;
* repas sautés → priorité à un repas régulier ;
* hydratation insuffisante → actions liées à l’eau ;
* profil déjà régulier → programme de consolidation.

La priorité principale doit être visible dans le résumé du programme et revenir de manière cohérente pendant la semaine.

Les sept journées doivent suivre une progression :

* Jour 1 : démarrage et action la plus simple ;
* Jour 2 : environnement et préparation ;
* Jour 3 : première consolidation ;
* Jour 4 : régularité ;
* Jour 5 : approfondissement ;
* Jour 6 : défi réaliste ;
* Jour 7 : bilan et préparation de la suite.

Ne pas simplement copier les trois mêmes textes pendant sept jours.

CONTENU COMMERCIAL

Employer un ton positif, motivant, direct et personnel.

Le produit doit présenter les actions comme une manière de :

* construire une routine favorable ;
* améliorer la régularité ;
* protéger son potentiel ;
* suivre ses habitudes ;
* préparer la prochaine mesure.

Interdire dans la bibliothèque les formulations suivantes :

* « gagne X cm grâce à cette action » ;
* « augmente ta taille de X cm » ;
* « résultat garanti » ;
* « cet exercice te fera grandir » ;
* toute promesse médicale ou chiffrée attribuée à une action.

MESURE DE LA TAILLE

Ne pas demander une mesure quotidienne.

Le Jour 1 peut expliquer brièvement comment réaliser une mesure propre et reproductible, mais la prochaine vraie comparaison doit être prévue beaucoup plus tard.

Ne pas interpréter quelques jours d’utilisation comme une modification de la taille.
